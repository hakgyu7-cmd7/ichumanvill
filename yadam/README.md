# 시니어 롱폼 야담 제작 키트

50~70대가 즐겨 보는 10분 야담 한 편을, 사람이 편집 프로그램을 만지지 않고 AI에게 지시해서 만드는 키트입니다.
실사 AI 드라마(Kling, Veo, 립싱크)보다 비용과 난이도가 훨씬 낮습니다.
승부처는 영상 퀄리티가 아니라 **대본, 제목, 첫 30초**입니다.

참고한 자료:
- 리드어세상 6화 「시니어 롱폼, 400만 원 강의 날린 사람의 제작 노하우 대방출」(youtu.be/1b0_B-NWm3I)
- 같은 영상의 무료 자료실 (readasesang-lab.vercel.app/v6/)

이 키트의 대본, 인물, 그림 지시문은 모두 새로 쓴 것입니다.
자료실에서는 분석 방법과 작업 순서만 가져왔습니다.

## 도구와 비용

| 하는 일 | 도구 | 비용 |
|---|---|---|
| 기획, 대본, 장면표, 편집 지시 | Claude (앱 또는 Claude Code) | Claude 요금제 |
| 인물 시트, 장면 그림 | ChatGPT 이미지 (한 대화에서 이어 만들기) | ChatGPT 요금제 |
| 맨 앞 30초 영상 4개, 배경 음악 | Google Flow | Flow 크레딧 (영상 하나마다 듦) |
| 목소리 | Supertonic (메모리 16GB 미만) 또는 Qwen3-TTS (16GB 이상) | 무료, 내 컴퓨터에서 돔 |
| 자막 시각 맞추기 | Whisper | 무료 |
| 영상 조립 | HyperFrames (Claude Code가 다룸) | 무료 오픈소스 |

6화 진행자의 첫 편은 **5시간 30분**이 걸렸습니다(준비 1시간 20분, 제작 4시간 남짓, 그중 목소리 다듬기 1시간 30분).
따로 든 돈은 AI 요금제와 Flow 영상 크레딧뿐이었습니다.
첫 편은 그보다 오래 걸려도 괜찮습니다. 걸린 시간을 `제작기록.md`에 적어 두면 다음 편에서 줄어든 곳이 보입니다.

## 다음 편 만들기

이 저장소를 Claude Code로 열고 `/yadam-episode`라고 부르면 `ep02/`부터 같은 구성으로 만듭니다.
(스킬 파일: `.claude/skills/yadam-episode/SKILL.md`)

1. **기준과 레퍼런스 (처음 한 번, 이후 석 달마다)**
   - 구독자 구간 3개(1만 이하, 약 5만, 약 10만)에서 「평소 조회수(중앙값)의 5배 이상 + 최소 조회수」를 넘은 영상만 잘 된 영상으로 봅니다.
   - 최소 조회수는 소형 1만, 중형 5만, 대형 10만 회입니다.
   - 평범한 영상은 0.5~1.5배입니다. 잘 된 영상 9편과 평범한 영상 6편, 모두 15편을 모읍니다.
   - `tools/finder.html`(더블클릭해서 여는 웹페이지)이나 `tools/find_hits.py`가 채널 목록이나 검색어만 넣으면 이 판정과 표본 고르기를 해 줍니다. 사용법은 `tools/README.md`에 있습니다.
   - Claude 앱에서 리드어세상의 `senior-longform-studio` 스킬을 쓰면 이 단계를 대화로 진행합니다. 스킬 zip은 자료실에서 받아 「사용자 지정 → Skills → Skill 업로드」로 넣습니다.
2. **주제**: 제목에 관계가 끊어지는 사건과 세월 숫자를 넣고, 첫 장면을 그 끊어지는 순간으로 엽니다.
3. **대본** → 4. **인물 시트** → 5. **장면표** → 6. **목소리·음악** → 7. **썸네일·제목** → 8. **조립·점검**: `ep01`과 같은 순서입니다.

## 지킬 것

- 영상과 설명란에 「AI로 만든 이야기입니다」, 「영상 속 목소리는 AI로 만들었습니다」를 적습니다.
- 「실화」, 「실제 사연」이라고 내세우지 않습니다.
- 남의 채널 이름, 제목, 썸네일, 장면은 분석에만 쓰고 내 영상에 넣지 않습니다. 패턴만 배웁니다.
- 크레딧이 드는 생성 버튼은 지시문과 시작 그림을 한 번 더 보고 누릅니다.
- 분석 결과는 표본 15편에서 나온 것입니다. 「법칙」이 아니라 「이 표본에서는 이렇게 보였다」로 읽습니다.
