# 잘 된 영상 찾기 (`find_hits.py`)

리드어세상 6화 1단계 「영상보다 기준부터 정하기」를 프로그램으로 만든 것입니다.
채널을 넣으면 최근 영상을 모아 다음을 해 줍니다.

1. 채널마다 **평소 조회수**(판정 대상 영상 조회수의 중앙값)를 구합니다.
2. 영상마다 **성과 배수**(조회수 ÷ 평소 조회수)를 계산합니다.
3. 영상을 **잘 됨 / 평범 / 보류 / 제외**로 판정합니다.
4. **표본 15편**을 골라 줍니다.

## 가장 쉬운 방법: 웹페이지 `finder.html` (설치 없음)

1. 깃허브에서 `yadam/tools/finder.html`을 열고 오른쪽 위 **다운로드 버튼(아래 화살표)** 을 누릅니다.
2. 「다운로드」 폴더의 `finder.html`을 **더블클릭**하면 크롬이나 엣지에서 열립니다.
3. API 키를 넣고, 검색어(또는 채널 목록)를 확인한 뒤 **찾기 시작**을 누릅니다.
4. 결과 표가 화면에 나오고, **표본 CSV 내려받기** 버튼으로 엑셀 파일을 받을 수 있습니다.

키는 그 컴퓨터 브라우저에만 저장되고, YouTube API 말고 다른 곳으로 보내지 않습니다.
파이썬 프로그램과 판정 규칙이 같습니다(`node yadam/tools/test_finder.js`로 시험).

## 판정 기준 (분석 기준표 그대로)

| 항목 | 기준 |
|---|---|
| 채널 구간 | 소형 1천~1만, 중형 3만~7만, 대형 8만~15만 명 (그 사이는 일부러 비움) |
| 롱폼 | 8분 이상. 쇼츠와 라이브는 뺌 |
| 기간 | 수집일 직전 92일 안에 올라왔고, 올린 지 14일 넘은 영상 |
| 잘 됨 | 평소의 5배 이상 **그리고** 최소 조회수 이상 (소형 1만, 중형 5만, 대형 10만) |
| 평범 | 평소의 0.5~1.5배 |
| 보류 | 그 밖 (경계에 걸친 영상은 빼야 두 집단 차이가 선명함) |
| 광고 유입 의심 | 좋아요율이 채널 중앙값의 1/3 미만이면 뺌 |
| 채널 자격 | 판정 대상 영상 6편 이상 |
| 표본 | 구간마다 채널 3개에서 잘 된 영상 1편씩, 그중 배수 높은 2편에 같은 채널의 업로드일이 가장 가까운 평범한 영상을 짝지음. 모두 15편 |

잘 된 영상이 모자라도 기준을 낮추지 않습니다. 후보 채널을 늘립니다(구간당 10개에서 20개로).

## 방법 1. YouTube API 키로 자동 수집 (추천)

### API 키 받기 (한 번만, 무료)

1. console.cloud.google.com 에 구글 계정으로 들어갑니다.
2. 위쪽에서 「프로젝트 선택 → 새 프로젝트」로 프로젝트를 하나 만듭니다.
3. 「API 및 서비스 → 라이브러리」에서 **YouTube Data API v3**를 찾아 「사용」을 누릅니다.
4. 「API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키」를 누르면 키가 나옵니다.
5. 키는 비밀번호처럼 다룹니다. 채팅, 깃허브, 스크린샷에 올리지 않습니다.

하루 무료 할당량은 10,000입니다.
채널 30개를 넣으면 보통 100 안팎을 씁니다.
검색(`--search`)은 한 번에 100을 씁니다.

### 실행

```bash
# 키를 환경 변수로 (맥·리눅스)
export YOUTUBE_API_KEY=여기에_키

# 1) 내가 고른 채널 목록으로
python3 yadam/tools/find_hits.py --channels yadam/tools/채널목록_양식.txt

# 2) 검색어로 채널을 찾아서 (구간에 맞는 채널만 씀)
python3 yadam/tools/find_hits.py --search "야담,옛날이야기,시니어 사연,사연 라디오"
```

윈도우 명령 프롬프트에서는 `export` 대신 `set YOUTUBE_API_KEY=여기에_키`를 씁니다.

## 방법 2. API 키 없이 직접 모은 표로

`영상표_양식.csv`를 엑셀로 열어 한 줄에 영상 하나씩 채웁니다.

| 열 | 꼭 | 예 |
|---|---|---|
| channel | O | 채널 이름 |
| subscribers | O | `52,000` 또는 `5.2만` |
| title | O | 영상 제목 |
| published | O | `2026-09-01` |
| seconds | O | `24:10` 또는 `1450` |
| views | O | `120,000` 또는 `12만` |
| likes, comments, url, channel_url, is_live | | 비워도 됨. 라이브 다시보기면 is_live에 `예` |

```bash
python3 yadam/tools/find_hits.py --from-csv 내가_모은_영상.csv
```
