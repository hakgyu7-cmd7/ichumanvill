# 목소리와 배경 음악

## 1. 먼저 정할 것: 내레이터 한 명

**이 편은 내레이터 한 명이 대사까지 모두 읽습니다.**

자료실의 `13_목소리다듬기_프롬프트.md`는 4단계에서 인물마다 다른 목소리를 넣으라고 합니다.
하지만 리드어세상 6화 영상(21:49~23:00)에서 실제로 해 보니 결과가 달랐습니다.

- 인물마다 목소리를 나누자 틀리게 읽은 문장이 6개 다시 생겼습니다.
- 들어 보니 「오히려 어색」했습니다.
- 레퍼런스 10편을 다시 보니 모두 내레이터 한 명이었습니다.
- 그래서 최종본은 여성 내레이터 한 명으로 만들었습니다.

여성 내레이터를 기본으로 하되, 후보를 직접 들어 보고 고릅니다.
AI는 소리를 직접 듣지 못하고 받아쓰기 숫자로만 고릅니다. 마지막 결정은 사람이 귀로 합니다.

## 2. 목소리 엔진 고르기

| 내 컴퓨터 메모리 | 엔진 | 특징 |
|---|---|---|
| 16GB 이상 | Qwen3-TTS (github.com/QwenLM/Qwen3-TTS) | 억양이 사람처럼 풍부합니다. 무겁고 느립니다. |
| 16GB 미만 | Supertonic (github.com/supertone-inc/supertonic) | 가볍고 그래픽 카드 없이 돕니다. 8GB 노트북에서도 됩니다. |

- 메모리 확인: 맥은 사과 메뉴 → 「이 Mac에 관하여」, 윈도우는 설정 → 시스템 → 정보.
- 상업 이용 조건과 표기 의무는 바뀔 수 있습니다. 쓰기 전에 각 깃허브 안내를 확인합니다.
- 설명란에 「영상 속 목소리는 AI로 만들었습니다」를 적습니다.

## 3. 낭독용 글

`03_낭독용.txt`를 씁니다. 대본에서 구간 머리, 시각, 채널 인사 자리를 뺀 글입니다.
나이와 숫자는 이미 한글로 적었습니다(예순하나, 스물다섯, 삼백 냥, 이백 그릇).
자료실 경험으로는 「63살」처럼 숫자로 두면 뭉개지고, 「예순세 살」로 적으면 바로 맞게 읽었습니다.

1차에서 귀로 꼭 확인할 낱말:

| 낱말 | 걱정되는 점 | 틀리면 바꿀 표기 후보 |
|---|---|---|
| 환갑상 | 「환갑쌍」 소리가 맞음 | 환갑쌍 |
| 한 순배 | 낯선 말 | 한 순배, 한순배 |
| 말미 | 짧아서 뭉개짐 | 말미를 |
| 됫박 | 받침 발음 | 되빡 |
| 굴뚝 | 받침 발음 | 굴뚝 |
| 행수 | 「항수」로 들릴 수 있음 | 행수 어른 |
| 덕배, 덕만, 덕수 | 이름끼리 헷갈림 | 쉼을 조금 더 줌 |

## 4. Claude Code에 붙여 넣을 지시문

이 저장소를 Claude Code로 연 상태에서 보냅니다.
한 번에 다 고치지 말고, 1차로 어디가 이상한지부터 찾습니다.

### 4-1. 1차 만들기

```text
yadam/ep01/03_낭독용.txt를 무료 AI 목소리로 읽혀서 영상용 목소리를 만들려고 해. 내 컴퓨터 메모리는 [8GB]야.

1. [Supertonic]이 없으면 설치부터 해 줘. 처음 하는 사람이라 단계마다 무엇을 하는지 한 줄씩 알려 줘.
2. 목소리 후보(여자·남자 전부)로 첫 문단을 하나씩 만들어 yadam/ep01/음성/후보/ 에 넣어 줘. 이 편은 내레이터 한 명이 대사까지 모두 읽는다. 야담에 어울리는 차분한 여성 목소리를 1순위로 골라 이유를 말해 줘.
3. 고른 목소리로 전체를 문장 단위로 만들어 yadam/ep01/음성/1차.wav로 저장해 줘. 씨앗값은 고정해 줘.
4. 무료 whisper 두 모델(turbo, large-v3)로 다시 받아써서, 두 모델이 같은 자리를 똑같이 틀리게 들은 문장, 너무 빠른 문장, 숫자·옛말을 이상하게 읽은 곳을 표로 정리해 줘.

아직 고치지 말고 어디가 부자연스러운지만 알려 줘.
```

### 4-2. 다듬기 (한 단계씩)

```text
이제 한 단계씩 다듬자. 단계마다 무엇을 바꿨는지 yadam/ep01/음성/다듬기_기록.md에 남기고, 단계 파일은 yadam/ep01/음성/_작업/에 저장해 줘.

1. 읽기: 틀리게 읽은 낱말마다 표기 후보 여러 개를 만들어 보고, 받아쓰기 두 모델이 모두 바르게 들은 표기만 써. 자막은 원래 대본 그대로 둬.
2. 쉼: 문장 사이, 문단 사이, 따옴표 대사 앞뒤의 쉼을 다르게. 맨 앞 30초는 조금 빠르게, 마지막 문단은 느리게.
3. 속도: 같은 구간 가운데값보다 10% 넘게 빠른 문장만 가운데값까지 늦춰. 짧은 문장이 휙 지나가지 않게.
4. 다시 만들기: 받아쓰기 두 모델이 같은 자리를 틀린 문장만 씨앗값이나 표기를 바꿔 다시 만들어.
5. 마무리: 유튜브 기준 음량(-14 LUFS, 최고 -1 dBTP)으로 맞춰 yadam/ep01/음성/최종.wav로 저장하고 다시 받아써서 확인해.

인물마다 목소리를 나누지는 마. 내레이터 한 명으로 간다.
1차와 최종을 같은 문단으로, 같은 음량으로 맞춘 비교 듣기 파일(음성/비교_1차대최종.wav)도 만들어 줘.
```

### 4-3. 중간에 쓰는 짧은 지시

| 이럴 때 | 이렇게 말합니다 |
|---|---|
| 한 문장만 이상하다 | `37번 문장만 씨앗값을 바꿔 다섯 번 다시 만들고, 받아쓰기 두 모델로 판정해 가장 나은 것으로 바꿔 줘.` |
| 받아쓰기는 틀렸다는데 내 귀엔 맞다 | `'됫박'은 내가 들어 보니 맞게 읽었어. 받아쓰기 버릇으로 표시하고 다시 만들지 마.` |
| 전체가 빠르다 | `본문 빠르기를 한 단계 낮추고 2단계부터 다시 해 줘.` |
| 자막이 필요하다 | `최종 음성에 맞춰 자막(srt)을 만들어 줘. 글은 02_대본.md 원문 그대로, 한 줄 18자 안쪽, 어절 중간에서 끊지 말고.` |

## 5. 배경 음악 (Google Flow 음악)

```text
조선시대 야담 배경 음악. 가야금과 대금, 잔잔한 장구. 늦가을 비 오는 장터의 쓸쓸함에서 시작해 끝부분은 따뜻하게. 가사 없이, 3분 안팎, 느리게.
```

- 점 세 개 메뉴에서 WAV로 내려받아 `yadam/ep01/음악/배경음악.wav`로 둡니다.
- 사람 목소리(가사)가 없는지 확인합니다.
- 조립할 때 목소리보다 훨씬 작게 깔고, 모자라면 자연스럽게 이어 반복합니다.

## 6. 확인표

- [ ] 나이와 숫자를 모두 맞게 읽었다.
- [ ] 받아쓰기 두 모델이 같은 자리를 틀린 문장이 0개이거나, 남은 것은 귀로 확인했다.
- [ ] 따옴표 대사 앞뒤에 숨 고르는 쉼이 있다.
- [ ] 맨 앞 장면은 팽팽하고, 끝 장면은 여유 있다.
- [ ] 최종 음량이 -14 LUFS 근처, 최고값이 -1 dBTP 아래다.
- [ ] 음악에 가사가 없다.
