# 조립과 업로드 전 점검

편집 프로그램(캡컷, 브루)을 쓰지 않고 Claude Code가 HyperFrames(HTML로 영상을 만드는 무료 오픈소스 도구, hyperframes.heygen.com)로 조립합니다.
리드어세상 6화에서는 렌더(영상 파일로 뽑기) 약 13분을 포함해 완성까지 약 23분이 걸렸습니다.

## 1. 파일 놓는 자리

| 파일 | 자리 |
|---|---|
| 다듬은 목소리 | `yadam/ep01/음성/최종.wav` (조립의 기준 시간축) |
| 하이라이트 영상 4개 | `yadam/ep01/영상/하이라이트1.mp4` ~ `하이라이트4.mp4` |
| 장면 그림 23장 | `yadam/ep01/그림/장면05.png` ~ `장면27.png` (번호는 장면표와 같게) |
| 배경 음악 | `yadam/ep01/음악/배경음악.wav` |
| 장면표, 대본 | `yadam/ep01/05_장면표.md`, `yadam/ep01/02_대본.md` |

그림, 영상, 음성 파일은 용량이 커서 저장소에 올리지 않도록 `.gitignore`에 넣어 두었습니다.

## 2. Claude Code에 붙여 넣을 지시문

```text
HyperFrames로 yadam/ep01 한 편을 영상으로 조립해 줘. 나는 편집 프로그램을 쓰지 않을 거야.
HyperFrames가 없으면 설치부터 해 주고, 단계마다 무엇을 하는지 한 줄씩 알려 줘.

- 기준 시간축: yadam/ep01/음성/최종.wav
- 맨 앞: 영상/하이라이트1~4.mp4를 0:00부터 차례로. 클립 소리는 끄거나 아주 작게.
- 그 뒤: 05_장면표.md 순서대로 그림/장면05~27을 놓아 줘. 장면이 바뀌는 시각은 장면표의 어림 시각이 아니라, 그 장면의 대본 문장이 실제로 읽히기 시작하는 시각에 맞춰 줘. 장면표의 카메라 움직임(줌인, 줌아웃, 패닝)을 천천히 주고, 장면이 바뀔 때 0.5초 부드럽게 섞어 줘.
- 자막: 무료 whisper로 목소리에 시각을 맞추되, 글은 02_대본.md 원문 그대로. 한 줄 18자 안쪽, 어절 중간에서 끊지 말고. 화면 아래 반투명 상자에 흰 글씨.
- 채널 인사 자리(0:41 무렵)에는 [내 채널 인사 녹음 파일 또는 비워 두기].
- 배경 음악: 음악/배경음악.wav를 목소리보다 훨씬 작게, 모자라면 자연스럽게 이어 반복, 끝에서 서서히 줄이기.
- 끝: 마지막 말 뒤 3초 동안 어둡게 사라지기.
- 1920x1080으로 yadam/ep01/완성/완성.mp4에 뽑아 줘.

다 만든 뒤에는 너와 별개인 점검자(서브에이전트)가 장면 순서와 자막 글자를 대본과 하나하나 맞춰 보고, 걸린 곳을 고친 뒤 결과를 알려 줘.
걸린 시간도 기록해 줘.
```

## 3. 업로드 전 점검표

완성 영상을 처음부터 끝까지 한 번 봅니다. 대표 장면 몇 개만 보고 끝내지 않습니다.

**이야기**
- [ ] 첫 문장이 맏아들의 대사로 시작하고, 30초 안에 쫓겨나는 장면이 있다.
- [ ] 제목과 썸네일 문구가 이야기 내용과 맞는다.
- [ ] 나이(예순하나), 세월(마흔 해, 스물다섯 해), 돈(삼백 냥)이 앞뒤 맞는다.

**그림과 영상**
- [ ] 장면마다 옥분의 점과 비녀, 행수의 흉터가 같다.
- [ ] 그림체가 한 영상 안에서 흔들리지 않는다.
- [ ] 얼굴과 손이 자막에 가리지 않는다.
- [ ] 화면에 생성 그림의 글자나 워터마크가 없다.
- [ ] 남의 영상 장면(레퍼런스)이 들어가지 않았다.

**소리와 자막**
- [ ] 목소리가 처음부터 끝까지 잘 들리고, 음악이 목소리를 덮지 않는다.
- [ ] 하이라이트 클립 소리가 목소리와 부딪히지 않는다.
- [ ] 끝에서 소리가 갑자기 끊기지 않는다.
- [ ] 자막 글자가 대본 원문과 같고 한 줄 18자 안쪽이다.

**설명란과 설정**
- [ ] 설명란 맨 위에 AI 창작 안내와 AI 목소리 안내가 있다.
- [ ] 레퍼런스 채널 이름과 주소를 적지 않았다.
- [ ] 유튜브 업로드 화면에서 「변경되거나 합성된 콘텐츠」 질문에 정직하게 답했다.

**기록**
- [ ] 단계마다 걸린 시간을 `yadam/제작기록.md`에 적었다. 다음 편에서 어디가 줄었는지 비교합니다.
