# sleep-retention — 수면 영상의 시청 지속 읽기

수면 영상의 그래프는 일반 영상과 읽는 법이 다르다. 사람들이 잠들기 때문에 **완만하게 줄어드는 건 정상**이다. 문제는 두 가지뿐이다.

1. **초반 이탈** (처음 1~3분): "오늘 이걸로 잘까" 고르다 떠난 사람. 원인은 거의 항상 **제목·썸네일과 첫인사가 기대와 다르거나, 목소리·배경음이 안 맞는 것**이다. 대본 본문 문제가 아니다.
2. **초반 이후의 급격한 절벽**: 잠든 사람을 **깨운** 무언가가 있었다는 뜻이다. 큰 소리, 갑작스러운 배경음 변화, 중간광고, 화면이 확 밝아지는 그림 같은 것들이다.

## 데이터 받는 법 (사용자에게 안내)
YouTube Studio → 콘텐츠 → 영상 선택 → 분석 → **참여도** 탭 → '시청자 유지율' 그래프 오른쪽 위 **다운로드(↓)** → CSV.
영상 길이(예: 3:02:15)도 같이 받는다.

## 분석 도구 (반드시 돌린다)
```bash
python "<이 스킬 폴더>/retention_sleep.py" retention.csv --duration 3:02:15
python "<이 스킬 폴더>/retention_sleep.py" retention.csv --duration 3:02:15 --transcript 자막.srt
```
`--transcript`에는 SRT/VTT 자막 파일이나, 숏폼 추출기(`shorts-generator`)가 만든 `output/영상이름/transcript.json`을 넣을 수 있다. 넣으면 절벽 지점의 대사가 같이 나온다.

## 해석 기준
- **초반 이탈** (처음 3분, 또는 영상의 10% 중 짧은 쪽): 20%p 이하면 좋음, 35%p 넘으면 첫인사와 제목·썸네일을 먼저 고친다.
- **절반 지점** (시청자가 절반으로 줄어드는 시점): 늦을수록 좋다. 같은 채널의 다른 영상과 비교해야 의미가 있으니, 가능하면 2~3개 영상의 결과를 나란히 놓고 본다.
- **절벽**: 도구가 보여준 시점의 대사와 화면을 확인한다. 대사가 평범하면 그 시점의 배경음, 그림 전환, 중간광고 위치를 사용자에게 확인해달라고 한다.

## 돌려줄 것
- **가장 큰 문제 하나**와 그것을 위해 다음 영상에서 바꿀 **한 가지**. 목록 다섯 개가 아니라 하나.
- 초반 이탈이 낮고 절벽도 없는데 조회수가 낮다면, 영상은 괜찮고 **제목·썸네일 문제**라고 말해준다 → `sleep-package` 스킬로 넘긴다.
- 대본 때문으로 보이는 절벽이면 `sleep-script` 규칙 중 어떤 것을 지키면 되는지 알려준다 (예: 큰 의성어를 서술로 바꾸기).

마지막 줄은 항상 이 질문으로 끝낸다: **이 방향으로 다음 영상을 바꿔볼까요?**
