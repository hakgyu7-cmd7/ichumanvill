# sleep-package — 제목 + 썸네일

제목과 썸네일은 **하나의 세트**다. 같은 말을 두 번 하면 클릭할 이유가 반으로 준다. 썸네일은 그림과 짧은 문구로 분위기와 이야기의 핵심을, 제목은 용도·장르·길이와 이야기 소재를 맡는다.

## 쓰기 전에
1. 프로젝트 루트의 `youtube/channel.md`를 읽는다. 특히 '중간광고' 설정, '반응이 좋았던 영상', 영상 길이를 본다.
2. 영상의 이야기 제목(들), 전체 길이, 중간광고 여부를 확인한다. 모르면 묻는다.

## 수면 채널 제목의 재료
시청자는 "오늘 밤 틀어둘 것"을 찾는다. 그래서 아래 재료가 **앞부분에** 있어야 한다 (휴대폰 홈 화면에서는 앞의 약 20글자만 눈에 들어온다).
- **용도**: 잠잘 때 / 잠 안 올 때 / 잠들기 전
- **장르**: 옛날이야기 / 민담 / 야담 / 전래동화
- **길이**: 3시간 / 몰아듣기 / 모음
- **이야기 소재**: 사람이 등장하는 한 줄 (예: "장터에서 쫓겨난 과부")
- (중간광고를 실제로 껐을 때만) **중간광고 없음**

자극 표현(충격, 소름, 발칵, !!)은 쓰지 않는다. 잠들려는 사람에게는 역효과다. 이모지는 🌙 같은 차분한 것 1~2개까지.

## 검사 도구 (반드시 돌린다)
이 스킬 폴더의 `title_ko.py`로 검사한다. 한글 폭을 영문의 2배로 계산하고, 핵심 단어가 앞부분에 있는지 본다.

```bash
python "<이 스킬 폴더>/title_ko.py" --title "제목" --thumb "썸네일 문구"
python "<이 스킬 폴더>/title_ko.py" titles.txt --thumb "썸네일 문구"   # 후보 여러 개를 점수순으로
```

점수는 참고값이다. 낮게 나와도 이유가 분명하면(예: 시리즈 고정 형식) 그대로 써도 된다고 말해준다.

## 진행 순서
1. 제목 후보를 **10개** 쓴다. 형식을 섞는다:
   - 용도 먼저: "🌙잠 안 올 때 듣는 옛날이야기 | 장터에서 쫓겨난 과부 | 3시간"
   - 이야기 먼저: "장터에서 쫓겨난 과부가 삼십 년 뒤 받은 편지 | 잠잘 때 듣는 민담"
   - 모음형: "잠이 솔솔 오는 민담 5편 몰아듣기 | 효자·도깨비·과부 이야기"
2. 10개를 파일로 저장해 `title_ko.py`로 한꺼번에 검사한다.
3. 상위 3개를 점수, 휴대폰 앞부분 미리보기, 고칠 점과 함께 보여준다.
4. 1위 제목에 맞는 **썸네일 설계**를 쓴다:
   - 문구: 2~4단어, 제목과 다른 단어 (예: 제목이 "장터에서 쫓겨난 과부"면 썸네일은 "삼십 년 뒤")
   - 그림: 주인공 한 명이 크게, 따뜻한 등불이나 달빛, 어두운 남색·갈색 배경
   - 글씨: TV와 휴대폰 작은 화면에서도 읽히게 굵고 크게, 배경과 대비되는 노란색·흰색
   - 채널 고정 요소 (시리즈 로고, 같은 위치의 달 그림 등)

## 돌려줄 것
- 상위 3개 제목 (점수, 앞부분 미리보기, 고칠 점)
- 1위 제목의 썸네일 설계 (문구, 그림, 색, 글씨)
- 설명란 첫 두 줄 (검색 결과와 "더보기" 위에 보이는 부분): 무슨 이야기가 몇 편, 몇 시간인지

마지막 줄은 항상 이 질문으로 끝낸다: **이대로 쓸까요, 고칠 곳이 있을까요?**
