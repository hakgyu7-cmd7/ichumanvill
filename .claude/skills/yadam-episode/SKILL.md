# 야담 한 편 만들기

`yadam/ep01/`이 이 스킬의 완성 예시다.
새 편은 같은 파일 구성과 같은 형식으로 만든다.
시작하기 전에 `yadam/README.md`와 `yadam/ep01/`의 파일을 모두 읽는다.

## 1. 묻기 (한 번에, 번호 선택지, 기본값 표시)

1. 주제: ① 주제 후보 5개를 받아서 고르기 (기본) ② 직접 한 줄 주제
2. 길이: ① 10분 (기본) ② 15분 ③ 20분
3. 내레이터: ① 여성 한 명 (기본) ② 남성 한 명
4. 계절·배경: ① 지난 편과 다르게 (기본) ② 직접 지정

답이 「기본」뿐이면 기본값으로 진행한다.
다음 편 번호는 `yadam/` 아래 가장 큰 epNN 다음 번호다.

## 2. 이야기 규칙

리드어세상 6화 표본(15편)에서 나온 패턴이다. 법칙이 아니라 가설로 다룬다.

- 제목에 관계가 끊어지는 사건(버림, 배신, 내쫓김, 이별)을 넣는다.
- 제목에 세월 숫자(N년, N해)를 넣는다.
- 첫 문장은 인물의 대사로, 장면 한가운데에서 시작한다. 인사, 질문, 「오늘은 이런 사연을」로 시작하지 않는다.
- 맨 앞 30초는 관계가 끊어지는 순간이나 가장 센 장면이다.
- 구성은 `ep01/01_기획.md`의 구성표 10구간(① 하이라이트 ~ ⑩ 결말)을 쓴다. 목표 글자는 1분에 263자(공백 빼고)로 잡는다.
- 소품 하나가 과거와 현재를 잇고 반전을 일으키게 한다.
- 지난 편들과 주인공 처지, 소품, 계절, 반전이 겹치지 않게 한다. `yadam/ep*/01_기획.md`를 읽고 확인한다.
- 리드어세상 자료실의 예시 이야기(늙은 머슴, 도둑 누명, 사또의 손자, 눈 오는 밤)와 겹치지 않게 한다.
- 폭력 장면(때리는 순간, 피, 무기)은 쓰지 않는다. Flow 영상이 막히고 시니어 시청자에게도 필요 없다.
- 실존 인물, 실제 사건, 실존 왕의 이름을 쓰지 않는다.

## 3. 만들 파일

`ep01`과 같은 이름, 같은 형식으로 만든다.

| 파일 | 내용 |
|---|---|
| `01_기획.md` | 근거 패턴 표, 주제 후보 5개, 로그라인, 제목 후보 3개, 인물표, 연표, 소품, 구성표 |
| `02_대본.md` | 머리 표, 구간별 대본, 점검 결과, AI 고지 문구 |
| `03_낭독용.txt` | 구간 머리와 표시를 뺀 읽을 글. 아라비아 숫자 0개 |
| `04_캐릭터셋_그림체.md` | 그림체 문구(편마다 계절 색을 바꿈), 인물 얼굴 고정 문구(영어), 옷 문구, ChatGPT·Flow 순서 |
| `05_장면표.md` | Flow 8초 영상 4개(시작 그림 + 움직임), 장면 그림 약 25초마다 1장, 카메라 움직임 |
| `06_썸네일_제목_설명란.md` | 문구 3안(아래 30~35%에 2줄, 줄마다 두 색, 밝은 배경), 그림 프롬프트, 제목 3개, 설명란 |
| `07_목소리_음악.md` | 내레이터 한 명 원칙, 엔진 고르기, 귀로 확인할 낱말 표, Claude Code 지시문, Flow 음악 지시문 |
| `08_조립_업로드점검.md` | HyperFrames 조립 지시문, 업로드 전 점검표 |

`yadam/제작기록.md`에 새 편의 빈 줄을 추가한다.

## 4. 점검 (대본을 쓴 뒤 꼭)

1. 구간별 글자 수를 센다(공백 빼고, 머리와 `(채널 인사 자리)` 제외). 목표와 25% 넘게 차이 나면 고친다.
2. 대본의 나이, 세월, 돈, 계절, 호칭, 이름을 인물표·연표와 하나씩 맞춘다. 사용자가 `senior-longform-studio`의 `check_consistency.py`를 갖고 있으면 그것을 돌린다.
3. 서브에이전트(새 맥락의 점검자)에게 대본과 기획을 주고 앞뒤 안 맞는 곳을 찾게 한다. 두 번 돌린다.
4. `03_낭독용.txt`에 아라비아 숫자가 없는지 확인한다. 나이는 「예순하나」처럼 한글로 적는다.
5. 대본 끝 「점검 결과」 표에 맞춰 본 항목을 적는다.

## 5. 지킬 것

- 사용자는 컴퓨터가 서툴 수 있다. 쉬운 우리말로 쓰고, 낯선 말은 처음 나올 때 괄호로 풀어 준다.
- 한 줄에 한 문장. em 대시(가로로 긴 줄표)를 쓰지 않는다.
- 숫자를 지어내지 않는다. 분석 근거에는 [확인], [가설], [참고 표본]을 붙인다.
- 조회수와 수익을 약속하지 않는다.
- 설명란 맨 위에 AI 창작 안내와 AI 목소리 안내를 넣는다. 「실화」라고 쓰지 않는다.
- 그림·영상·목소리·음악 파일은 이 스킬이 직접 만들지 않는다. 붙여 넣을 지시문과 어느 도구에 넣는지를 준다. 크레딧이 드는 생성은 사용자가 확인한 뒤 누르게 한다.
- 다 만들면 사용자에게 파일 목록과, 사람이 직접 할 단계(인물 시트, 장면 그림, Flow 영상, 목소리, 조립)를 순서대로 알려 준다.
