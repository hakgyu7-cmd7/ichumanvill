# sleep-outliers — 경쟁 채널에서 터진 영상 찾기

조회수가 큰 영상은 대부분 **큰 채널**의 영상이다. 그건 채널 크기를 잴 뿐 소재의 힘이 아니다. 그래서 영상마다 **그 채널 평소 조회수(최근 영상의 중앙값)의 몇 배인지**로 순위를 매긴다. 구독자 3천 명 채널에서 평소의 10배 나온 영상이 진짜 배울 거리다.

## 진행 순서
1. **비교할 채널 받기**: 사용자에게 비슷한 수면·옛날이야기 채널 주소를 5~10개 받는다. 모르면 YouTube에서 "잠잘 때 듣는 옛날이야기", "수면 민담", "야담 몰아듣기"로 검색해 나오는 채널을 고르라고 안내한다. 내 채널도 같이 넣으면 비교가 된다.
2. **수집** (yt-dlp가 설치된 내 PC에서 실행. 클라우드에서는 YouTube가 막을 수 있다):
   ```bash
   python "<이 스킬 폴더>/outliers.py" collect channels.txt -o data.json
   ```
   `channels.txt`에는 한 줄에 채널 주소 하나. 채널마다 최근 롱폼 60개를 읽는다 (`--limit`으로 조절). 공개 목록만 읽고 로그인하지 않는다.
3. **분석**:
   ```bash
   python "<이 스킬 폴더>/outliers.py" rank data.json          # 2배 이상
   python "<이 스킬 폴더>/outliers.py" rank data.json --min 3
   ```

## 결과 읽는 법
- **배수**가 핵심이다. 조회수 크기보다 배수를 본다.
- **"터진 제목에 자주 나온 요소"**는 터진 영상과 전체 영상에서 각 요소가 나오는 비율을 비교한 것이다. 배율이 높을수록 터진 쪽에 몰려 있다. 단, **같이 나왔다는 것이지 그 때문에 터졌다는 증명은 아니다.** 사용자에게도 그렇게 말한다.
- 터진 영상 수가 3개 미만이면 요소 분석은 우연일 수 있다고 알린다.

## 돌려줄 것
- 배수 상위 5개 영상과 각각의 공통점 (소재, 제목 형식, 길이)
- 터진 영상들이 공유하는 **구조적 공통점 하나**
- **이번 주 내 채널에서 만들 수 있는 소재 3개**. 내 말투와 형식(`youtube/channel.md`)에 맞게, 각각 한 줄 줄거리와 제목 초안 포함. 경쟁 채널의 이야기를 베끼지 말고, 같은 **유형**의 다른 민담을 고른다.

마지막 줄은 항상 이 질문으로 끝낸다: **이 중 어떤 소재로 대본을 써볼까요?** (고르면 `sleep-script` 스킬로 넘긴다)
