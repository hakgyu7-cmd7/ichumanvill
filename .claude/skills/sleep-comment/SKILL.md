# sleep-comment — 댓글 정리와 답글

수면 채널의 댓글에는 **"덕분에 잘 잤어요"**, **어릴 적 기억**, **이야기 요청**이 많다. 답글 하나가 다음 날 밤 다시 찾아오게 만든다. 그리고 요청 댓글은 그대로 다음 영상 소재가 된다.

## 쓰기 전에
1. 프로젝트 루트의 `youtube/channel.md`를 읽는다 (말투, 쓰지 않는 말, 하지 않는 주장).
2. 사용자가 붙여넣은 댓글 전체를 받는다. 작성자 이름이 있으면 같이 받는다.

## 먼저 분류한다 (답글 쓰기 전에 개수부터 보고)
1. **이야기 요청** — "○○ 이야기도 해주세요". 답글을 달고, `youtube/channel.md`의 '시청자 이야기 요청 목록'에 날짜와 함께 추가한다 (이미 있으면 요청 횟수를 늘린다).
2. **수면 후기·감사** — "듣다가 잠들었어요". 몇 개만 골라 짧게, 댓글 내용 중 하나를 콕 집어 답한다. 똑같은 "감사합니다!"를 여러 개 달면 기계처럼 보인다.
3. **추억·사연** — 어릴 적 할머니 이야기 등. 가장 정성 들여 답할 댓글이다. 사연에 공감하는 한두 문장.
4. **지적·불만** — 발음 오류, 내용 오류, 광고·음량·목소리 불만. 맞는 지적이면 인정하고 고맙다고 한다. 음량·광고 같은 반복 불만은 사용자에게 따로 알려준다 (다음 영상에서 고칠 것).
5. **스팸·악플** — 답하지 않는다. 숨기거나 신고를 권한다.

## 답글 쓰는 법
- **두 문장 이내.** 어르신은 긴 글보다 따뜻한 한마디를 반긴다.
- 존댓말. 호칭은 "○○님". 상대가 스스로 밝히지 않는 한 "어르신", "할머니"처럼 나이를 짚는 호칭은 쓰지 않는다.
- 이모지는 `channel.md`에 쓰라는 말이 없으면 🌙 하나 정도까지만.
- **약속하지 않는다**: "다음에 꼭 올릴게요" 대신 "요청 목록에 적어두었어요".
- 의학적인 말을 하지 않는다: "불면증에 좋아요" 금지. "편히 주무셨다니 다행이에요"까지만.

## 고정 댓글 추천
고정할 댓글 하나를 추천한다. 가장 많은 사람이 공감할 요청이나 질문을 고른다. 또는 채널이 직접 쓰는 고정 댓글 초안을 제안한다 (예: "다음에 듣고 싶은 옛날이야기를 댓글로 남겨주세요. 요청 많은 이야기부터 들려드릴게요 🌙").

## 돌려줄 것
- 분류별 개수
- 답글 초안 (댓글 원문 한 줄 → 답글), 복사하기 쉽게 정리
- 새로 추가한 이야기 요청 목록
- 사용자가 알아야 할 반복 불만 (있으면)
- 고정 댓글 추천

마지막 줄은 항상 이 질문으로 끝낸다: **이대로 다실까요, 고칠 곳이 있을까요?**
