## 말투 (AI 음성이 읽을 대본 기준)
- 해설: "~했습니다", "~했지요" 같은 차분한 존댓말. 문장은 짧고 쉽게.
- 등장인물 대사: 옛 말투 허용 ("~하오", "~하게", "~하거라"). 한 영상 안에서 같은 인물의 말투는 바꾸지 않는다.
- 첫인사 고정 문구: [ 예: "오늘 밤도 편안히 누우셨지요. 불은 끄시고, 눈은 살며시 감으셔도 좋습니다." ]
- 끝인사 고정 문구: [ 예: "오늘 이야기는 여기까지입니다. 좋은 꿈 꾸세요." ]

## 쓰지 않는 말
- 자극 표현: 충격, 경악, 소름, 발칵, 미쳤다
- 갑자기 크게 읽힐 말: 감탄사 연발("으악!", "꺄악!"), 큰 소리 의성어("쾅!", "어흥!")
- 영상 끝부분의 "구독·좋아요" 요청 (이미 잠든 사람을 깨운다)
- [ 내가 싫어하는 표현 추가 ]

## 하지 않는 주장
- 출처를 지어내지 않는다. 출전을 모르면 "전해 내려오는 이야기"라고만 한다.
- 수면·건강 효과를 의학적으로 단정하지 않는다 ("불면증이 낫는다" 같은 표현 금지).
- [ 추가 ]

## 영상 형식
- 길이: [ 예: 2~3시간, 이야기 3~5편 모음 ]
- AI 음성 서비스와 목소리: [ 예: 타입캐스트 / 클로바더빙 / ElevenLabs, ○○ 목소리 ]
- AI 음성 읽기 속도: [ 지난 영상에서 측정: 대본 글자 수(공백 포함) ÷ 영상 길이(분) = 분당 ○○자 ]
- 배경음: [ 예: 잔잔한 빗소리, 음량 아주 낮게 ]
- 화면: 그림 (그림 스타일: [ 예: 수묵화풍 / 동화책풍 ])
- 중간광고: [ 켬 / 끔 ]  ← 수면 채널은 중간광고가 잠을 깨워서 끄는 곳이 많음. 껐다면 제목에 "중간광고 없음"을 쓸 수 있음
